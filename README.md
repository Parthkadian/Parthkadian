## 🔥 Flagship Project: PulmoVision AI

<div align="center">
  
### 🫁 PulmoVision AI — Attention U-Net Lung Segmentation
**End-to-end medical imaging pipeline: Model → API → Dashboard**

*A complete AI system for automated lung segmentation from chest radiographs, built as a portfolio project demonstrating the full ML lifecycle.*

</div>

<table>
<tr>
<td width="50%" valign="top">

#### 🧠 Deep Learning Model
- **Architecture:** Attention U-Net with EfficientNetB0 encoder backbone
- **Input:** 256×256 grayscale chest X-rays
- **Filter progression:** 32 → 64 → 128 → 256 → 512
- **Attention gates** on all 4 decoder stages for spatial self-attention
- **Loss function:** Balanced BCE + Dice (0.5:0.5 weighting)
- **Regularization:** BatchNorm + Dropout(0.3) at every conv block
- **Augmentation:** Flips, 90° rotations, brightness/contrast jitter

#### 📈 Rigorous Evaluation
- **Test Dice:** 0.2745 (honest metric on 8-image held-out set)
- **IoU:** 0.1602
- **Precision:** 0.3078 | **Recall:** 0.2512
- **Inference latency:** ~900ms/image (CPU, TensorFlow 2.15)
- **Framework:** TensorFlow 2.15 + Keras
- **Dataset:** Indiana University Chest X-Ray Collection (55-image subset)

> **Transparency note:** Small dataset explains current metrics. Training on full 3,955-image dataset expected to achieve Dice >0.85. Model produces anatomically plausible lung masks with adaptive thresholding.

</td>
<td width="50%" valign="top">

#### ⚡ FastAPI Backend
- **Endpoint:** `/predict-full` — single-call inference
- **Response:** Mask + overlay + diagnostics (JSON)
- **Also provided:** `/health`, `/metrics`, `/model-info`, `/history`
- **Auto-generated:** Swagger UI at `/docs`
- **Format:** Pydantic schema-validated, OpenAPI 3.0

#### 📊 Streamlit Dashboard
- **8 interactive tabs:**
  - Original X-ray viewer
  - Binary segmentation mask
  - Clinical overlay (teal-colored)
  - Detailed diagnostics & QC verdict
  - AI analysis & coverage metrics
  - Export (PNG, JSON, CSV, ZIP)
  - Side-by-side comparison view
  - Training curve visualization
- **Real-time KPI strip:** Dice, IoU, latency, API health, success rate
- **Plotly analytics:** Coverage gauge, L/R distribution, performance radar
- **DICOM support:** `.dcm` file loading via PyDICOM
- **Session history:** Track predictions, coverage trends, reload results

</td>

#### 🎯 Key Engineering Decisions
- **Attention Gates:** Spatial self-attention allows the model to focus on clinically relevant lung regions
- **Adaptive Thresholding:** Percentile-based (p70–p85) rather than fixed threshold=0.5 (model sigmoid range is [0.20–0.49])
- **Rigorous Eval Pipeline:** `evaluate.py` computes real metrics on held-out set, not training set overfitting
- **DICOM Native:** Medical imaging requires proper file format handling—PyDICOM integration built in
- **Full-Stack Design:** Training infrastructure + REST API + interactive dashboard all in one repo
