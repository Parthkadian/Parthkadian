### Project 3: 🫁 PulmoVision AI
**Attention U-Net Lung Segmentation Platform**

<table>
<tr>
<td width="50%" valign="top">

#### 🧠 Deep Learning Model
- **Architecture:** Attention U-Net with EfficientNetB0 encoder backbone
- **Input:** 256×256 grayscale chest X-rays
- **Filter progression:** 32 → 64 → 128 → 256 → 512
- **Attention gates** on all 4 decoder stages for spatial self-attention
- **Loss function:** Balanced BCE + Dice (0.5:0.5 weighting)
- **Regularization:** BatchNorm + Dropout(0.3) at every conv block
- **Augmentation:** Flips, 90° rotations, brightness/contrast jitter

#### 📈 Rigorous Evaluation
- **Test Dice:** 0.2745 (honest metric on 8-image held-out set)
- **IoU:** 0.1602 | **Precision:** 0.3078 | **Recall:** 0.2512
- **Inference latency:** ~900ms/image (CPU, TensorFlow 2.15)
- **Framework:** TensorFlow 2.15 + Keras
- **Dataset:** Indiana University Chest X-Ray Collection (55-image subset)

> **Transparency:** Small dataset explains metrics. Full 3,955-image training expected >0.85 Dice. Model produces anatomically plausible masks with adaptive percentile thresholding.

</td>
<td width="50%" valign="top">

#### ⚡ FastAPI Backend
- **Endpoint:** `/predict-full` — single-call inference
- **Response:** Mask + overlay + diagnostics (JSON)
- **Also provided:** `/health`, `/metrics`, `/model-info`, `/history`
- **Auto-generated:** Swagger UI at `/docs`
- **Format:** Pydantic schema-validated, OpenAPI 3.0

#### 📊 Streamlit Dashboard
- **8 interactive tabs:** Original | Mask | Overlay | Diagnostics | Analysis | Export | Compare | Training Curve
- **Real-time KPIs:** Dice, IoU, latency, API health, success rate
- **Plotly analytics:** Coverage gauge, L/R distribution, performance radar
- **DICOM support:** Medical-grade `.dcm` file loading via PyDICOM
- **Session history:** Track predictions, coverage trends, reload results
- **Export:** PNG, JSON, CSV, ZIP formats

</td>
</tr>
</table>
