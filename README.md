### 🫁 Project 3 — PulmoVision AI
> **Attention U-Net Lung Segmentation Platform**

<table>
<tr>
<td width="50%" valign="top">

**🧠 Deep Learning Model**
- Architecture: Attention U-Net + EfficientNetB0 encoder
- Input: 256×256 grayscale chest X-rays
- Filter progression: 32 → 64 → 128 → 256 → 512
- Attention gates on all 4 decoder stages
- Loss: Balanced BCE + Dice (0.5:0.5)
- Regularization: BatchNorm + Dropout(0.3)
- Augmentation: Flips, rotations, brightness/contrast

**📈 Honest Evaluation**
- Test Dice: **0.2745** (8-image held-out set, honest)
- IoU: 0.1602 · Precision: 0.3078 · Recall: 0.2512
- Inference: ~900ms/image (CPU, TensorFlow 2.15)
- Dataset: Indiana University Chest X-Ray (55-image subset)

> ⚠️ Small dataset explains current metrics. Full 3,955-image training projected Dice **>0.85**. Model produces anatomically plausible masks with adaptive thresholding.

</td>
<td width="50%" valign="top">

**⚡ FastAPI Backend**
- `/predict-full` — single-call inference
- Response: Mask + overlay + diagnostics (JSON)
- Also: `/health` `/metrics` `/model-info` `/history`
- Auto-generated Swagger UI at `/docs`
- Pydantic schema-validated · OpenAPI 3.0

**📊 Streamlit Dashboard (8 Tabs)**
- Original · Mask · Overlay · Diagnostics · Analysis · Export · Compare · Training Curve
- Real-time KPIs: Dice, IoU, latency, API health, success rate
- Plotly analytics: Coverage gauge, L/R distribution, performance radar
- DICOM support: Medical-grade `.dcm` via PyDICOM
- Session history, export: PNG / JSON / CSV / ZIP

**🏗️ System Architecture**
```
Streamlit Dashboard  ←→  FastAPI Backend
                              ↓
                     Inference Engine
                     ├─ Preprocessing (DICOM, normalize)
                     ├─ Attention U-Net forward pass
                     └─ Mask refinement + overlay
```

</td>
</tr>
